# Gestión de Alumnos y Notas (PHP CRUD)

## Requisitos
- XAMPP (Apache + MySQL)
- PHP 8+
- Composer (para PDF/Excel)

## Instalación
1. Copiar el proyecto en: C:\xampp\htdocs\gestion_notas
2. Crear BD e importar: sql/schema.sql
3. (Opcional) Instalar librerías:
   composer install
4. Abrir:
   http://localhost/gestion_notas/public/

## Funcionalidades
- CRUD Alumno
- CRUD Nota (0 a 10)
- Promedio con 2 decimales + resultado cualitativo
- Exportar a PDF y Excel
